## Setup GitHub Pages

1. Push repo lên GitHub (private/public đều được, nhưng Pages cần public hoặc Pro plan)
2. Vào Settings → Pages
3. Source: `Deploy from a branch` → `main` / `/ (root)` → Save
4. Đợi 1-2 phút, URL sẽ active
